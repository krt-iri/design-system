Icon-only vs. Icon + Text

Zwei Regeln, ein einheitliches Set: wiederholte Zeilenaktionen (in jeder Tabellenzeile gleich) werden Icon-only mit aria-label/Tooltip — das spart Platz in dichten Oberflächen. Primäre & seltene Aktionen bleiben Icon + Text für Eindeutigkeit.

② Primäre & seltene Aktionen — Icon + Text

Vorher · Text allein
  • Funktioniert, aber das Auge muss jeden Button lesen; keine schnelle Wiedererkennung.
Nachher · Icon + Text
  • Icon als Anker beschleunigt das Wiederfinden; Text bleibt für Eindeutigkeit.
  • Icon sitzt links vom Text, gleiche Größe (1em), erbt die Button-Farbe.

Faustregel: Icon-only nur bei universell verständlichen, wiederholten Aktionen (edit/trash/check-in-out/bookout) — immer mit Label für A11y. Alles Primäre, Seltene oder Mehrdeutige: Icon + Text. Destruktive Einzelaktionen nie nur als Icon ohne Tooltip.
