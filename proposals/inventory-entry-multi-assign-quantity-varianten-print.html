Lagereintrag — Menge getrennt je Auftrag & Einsatz aufteilen

Je Eintrag wird die Gesamtmenge (z. B. 2.480 SCU) aufgeteilt — getrennt nach Aufträgen und nach Einsätzen. Beide Aufteilungen sind unabhängig und werden je gegen die Gesamtmenge abgeglichen (Verteilt / Rest). Aufträge = orange, Einsätze = blau. Offen ist nur noch die Platzierung (A/B/C).

Festgelegt

Modell G — getrennte Mengen. Die Menge wird zweimal unabhängig erfasst (über Aufträge, über Einsätze); jede Zuordnung trägt ein eigenes Mengenfeld. Abgleich: unverteilter Rest ist erlaubt (Rest > 0 = neutral „… frei“, Rest 0 = grün); nur Über-Verteilung (Rest < 0) ist unzulässig.

A Ausklappzeile · zwei getrennte Aufteilungen

Inline-Ausklappzeile (kein Overlay) — Empfehlung

Ein kompakter Button je Eintrag klappt unter der Zeile ein Panel mit zwei nebeneinanderliegenden Aufteilungen auf (links Aufträge, rechts Einsätze), je Liste Zuordnung + Menge und ein eigener Verteilt/Rest-Abgleich. Bleibt im Tabellenfluss; mehrere Einträge gleichzeitig offen.

Eintrag · Gesamtmenge 2.480 SCU · Panel aufgeklappt
Aufträge
#1042 Quantanium-Konvoi1.000 SCU
#1039 Laranite-Bestellung1.480 SCU
Verteilt 2.480 / 2.480Rest 0
Einsätze
Operation Nachtfalke · 05.05.1.000 SCU
Verteilt 1.000 / 2.480Rest 1.480 frei
Vorteile
  • Kein Overlay — bleibt im Tabellenfluss; mehrere Einträge gleichzeitig offen.
  • Beide Aufteilungen nebeneinander sichtbar, jede mit eigenem Rest-Abgleich.
  • Sofort wirksam; Zeile geschlossen schmal (ein Button).
Nachteile
  • Offene Panels erhöhen die Höhe (wie Notizen); viele offen = lange Tabelle.
  • Zwei Listen brauchen Breite — auf schmalen Screens untereinander.
B Modal · zwei getrennte Aufteilungen

Verwaltung im Modal

Derselbe Button öffnet ein Modal mit den zwei getrennten Aufteilungen (Layout wie oben), inkl. „Speichern“/„Abbrechen“ — gesperrt bei Über-Verteilung. Die Eintrags-Zeile bleibt unter allen Umständen minimal.

Modal „Mengen aufteilen“ · Gesamtmenge 2.480 SCU
Aufträge
#1042 Quantanium-Konvoi2.480 SCU
Verteilt 2.480 / 2.480Rest 0
Einsätze
Nachtfalke · 05.05.1.500 SCU
Aaron Halo · 12.05.980 SCU
Verteilt 2.480 / 2.480Rest 0
Vorteile
  • Zeile maximal kompakt — ein Button, egal wie viele Zuordnungen.
  • Viel Platz + eigener Rest-Balken je Dimension; bewusstes Speichern.
  • Vertrautes .krt-modal-Idiom (eine CTA, Abbrechen, Esc).
Nachteile
  • Aufteilung erst nach Klick sichtbar; Modal je Eintrag wirkt schwerer.
  • Nur ein Eintrag gleichzeitig bearbeitbar (kein Vergleich nebeneinander).
C Inline · Chips mit Mengen-Label

Chips mit Menge, direkt im Eintrag

Die leichteste Variante: je Gruppe stehen die Zuordnungen als Chips mit Menge direkt in der Zeile; Klick auf einen Chip öffnet einen Mini-Editor, „+ Zuordnen“ fügt hinzu. Ein kleiner Rest-Chip je Gruppe zeigt den Abgleich.

Eintrag · Gesamtmenge 2.480 SCU · Chips in der Zeile
Auftrag
#1042 · 1.000 #1039 · 1.480 Rest 0
Einsatz
Nachtfalke · 1.000 Rest 1.480 frei
Vorteile
  • Alles sichtbar ohne Klick; kein Overlay, kein Ausklappen.
  • Menge direkt am Chip; schnell für 1–2 Zuordnungen je Gruppe.
Nachteile
  • Wird eng — Chip + Menge + Rest je Gruppe blähen die Zeile bei mehreren Zuordnungen.
  • Mengen-Bearbeitung im Mini-Popover ist fummeliger als ein Tabellenfeld.

Empfehlung & offene Frage

Variante C für /inventory/my mit meist 1–2 Zuordnungen je Gruppe; Variante B (Modal), wenn die Zeile unter allen Umständen minimal bleiben soll.
