Inventar-Tabelle lesbarer machen

Die verschachtelte Material → Nutzer/Stack → Einträge-Tabelle wiederholt heute pro Ebene einen eigenen Großbuchstaben-Kopf (bei mehreren offenen Stacks mehrfach), hat keine Einrückung, linksbündige Zahlen und sehr geringe Dichte. Vorschlag: ein Spaltenkopf, klare Tiefen-Einrückung, rechtsbündige tabellarische Zahlen mit Qualitäts-Gauge.

  • Ein Spaltenkopf (sticky) für alle Ebenen statt drei wiederholter Köpfe.
  • Tiefen-Einrückung + Schienen: Material (Orange-Balken) → Nutzer → Eintrag klar gestaffelt.
  • Rechtsbündige Tabellenziffern + Qualitäts-Gauge (0–1000) → Werte auf einen Blick vergleichbar.
  • Höhere Dichte (0,5rem), Zebra-Hover; Köpfe hellgrau, Orange nur für Identität/Akzent.
  • Aktionen: „Ausbuchen" als Outline, „Notiz" als Ghost — statt zweier orange Textlinks.
  • Eintrag ohne Wiederholungs-Kopf: Auftrag/Einsatz als breite, beschriftete Selects im freigewordenen Bereich — lange Namen bleiben lesbar.
  • Notiz als eigene eingerückte Zeile (Orange-Label + Surface-Box, bis 80ch) mit Platz für den vollen Text; „Notiz"-Button wird Outline, wenn eine hinterlegt ist.
